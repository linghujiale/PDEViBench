# JSON schemas

| File | Describes |
|---|---|
| `pde_case.schema.json` | One task: design factors, problem specification, reference, thresholds and provenance |
| `trace.schema.json` | The turn-by-turn record of an agent run |
| `result.schema.json` | The verdict of the four-stage evaluation for one task, agent and repeat |

The schemas follow JSON Schema Draft 2020-12 and are validated with `jsonschema`.
